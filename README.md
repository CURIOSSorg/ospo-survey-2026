# OSPO Survey 2026

Data cleaning and analysis for the Fall 2026 CURIOSS OSPO survey.

## Tech Stack

- **R** with `renv` for dependency management
- **Quarto** for reproducible notebooks

## Project Structure

```
ospo-survey-2026/
├── _quarto.yml           # Quarto project configuration
├── config.yml            # Project configuration settings
├── process_raw_data.qmd  # Notebook: Converts raw data to analysis-ready TSV files
├── *.qmd                 # Analysis notebooks (can run in any order, except figures.qmd last)
├── data/                 # Sensitive data (NOT checked into version control)
│   ├── raw_data.xlsx     # Raw survey responses (manually cleaned)
│   ├── codebook.xlsx     # Data dictionary (manually created)
│   ├── *.tsv             # Analysis-ready output files (generated by process_raw_data.qmd)
│   ├── coding/           # Files for import into QualCoder
│   └── manually_curated/ # Hand-curated data files
├── pdfs/                 # PDF copies of analysis notebooks
├── renv/                 # R environment configuration
└── renv.lock             # R package versions
```

## Setup

1. Ensure R is installed.
2. Clone this repository and open the project.
3. Run `renv::restore()` to install the pinned package versions.
4. Create a `data/` folder at the project root and add it to `.gitignore` (if
   not already there).
   - This folder contains sensitive survey data and must not be committed to
     version control.
5. Within `data/`, create these subdirectories:
   - `coding/` - for files to be imported into QualCoder
   - `manually_curated/` - for hand-curated data files
6. Place your raw survey data in `data/raw_data.xlsx`.

## Workflow

### Data Preparation

1. **Manual cleanup** of `raw_data.xlsx`:
   - Remove spurious responses (e.g., test responses, duplicates)
   - Blank responses are acceptable and can be left in
2. **Create codebook** (`data/codebook.xlsx`):
   - Build by hand to define your data structure and variable mappings

3. **Run `process_raw_data.qmd`**:
   - Converts the cleaned raw data into analysis-ready TSV files
   - Outputs are saved to `data/` for use in subsequent notebooks

### Analysis

After running `process_raw_data.qmd`, you can run the analysis notebooks in any
order, **except**:

- Run `figures.qmd` last, after all other analysis notebooks have been executed

### Rendering to PDF

To render any notebook to PDF (which also executes the script):

```bash
quarto render <notebook_name>.qmd
```

## For Newcomers

Start by exploring the PDFs in `pdfs/` to understand the research process and
data structure. These documents provide a guided narrative through the analysis.
